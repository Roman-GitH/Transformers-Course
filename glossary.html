Cross-Lecture Glossary

42 terms (42 definitions) merged from the key-terms chapter of the published lectures. A badge such as L1 links to the lecture that gives that definition; the bracket shows the chapter.

A B C D E F H K L M N O P R S T V W

A

Accuracy

  • L1 Fraction of predictions that are correct. Misleading with imbalanced classes. (B0, C)

Activation / hidden state / context vector

  • L1 The vector an RNN keeps as a summary of the sequence so far; $\mathbf h_t$ (also $\mathbf a_t$). (B3)

Attention

  • L1 Mechanism giving a position a direct, learned, weighted link to other positions (2014); core of the Transformer. (B4)

B

BLEU (bilingual evaluation understudy)

  • L1 Reference-based translation metric; higher is better. (A, B0)

BOS / EOS tokens

  • L1 Special tokens marking the start and end of a sequence; generation stops when EOS is produced. (B6)

BPE (byte-pair encoding)

  • L1 Subword tokenizer that iteratively merges the most frequent adjacent pair (2026 lecture). (B1)

C

Causal / masked attention

  • L1 Self-attention in which position $i$ may only see positions $\le i$. (B6)

CBOW (continuous bag of words)

  • L1 word2vec variant: predict a word from the words around it. (B2)

Cell state

  • L1 Extra memory track $\mathbf c_t$ of an LSTM, next to the hidden state. (B3)

Cosine similarity

  • L1 $\cos\theta=\mathbf a\cdot\mathbf b/(\lVert\mathbf a\rVert\lVert\mathbf b\rVert)$; similarity of direction. (B2)

Cross-attention

  • L1 Attention whose queries come from the decoder and keys/values from the encoder output. (B6)

Cross-entropy

  • L1 Training loss $-\log$ of the probability given to the right word. (B2)

D

Decoder

  • L1 Half of the Transformer that produces the output sequence token by token. (B6)

E

Embedding

  • L1 Dense vector (size $D$, hundreds) representing a token; row of the embedding matrix. (B2)

Encoder

  • L1 Half of the Transformer that turns the input tokens into context-aware vectors. (B6)

F

F1 score

  • L1 Harmonic mean of precision and recall. (B0)

Feed-forward network (FFN)

  • L1 Two-layer network applied to each position after attention, with a wider hidden layer. (B6)

H

Head (attention head)

  • L1 One set of projections $W_Q,W_K,W_V$; multi-head attention uses $h$ of them in parallel and mixes them with $W_O$. (B5)

K

Key / Query / Value (K, Q, V)

  • L1 Three learned projections of the input; query–key similarity gives the weights, applied to the values. (B4)

L

Label smoothing

  • L1 Replace the one-hot target by $1-\varepsilon$ / $\varepsilon/(V-1)$ to make the model less over-confident. (B6)

Layer normalization

  • L1 Normalises the activations of a layer; helps convergence (2026 lecture). (B6)

LSTM (long short-term memory)

  • L1 RNN extension with a cell state to retain important information. (B3)

M

Multi-classification

  • L1 One label for each token of the text (NER, POS tagging). (A)

N

NER (named-entity recognition)

  • L1 Label words as location, time, person, … (A)

NLP

  • L1 Natural language processing – computing with text. (A)

O

One-hot encoding (OHE)

  • L1 Vector of length $V$ with a single 1 identifying the token. (B2)

OOV (out of vocabulary)

  • L1 Token not seen at training time; mapped to <unk>. (B1)

P

Perplexity

  • L1 $\exp$ of the average negative log-probability; how surprised the model is; lower is better. (B0)

Position encoding / embedding

  • L1 Vector added to each token embedding to inform on position; sinusoidal in the original paper. (B5)

Precision / Recall

  • L1 Correct share of the predicted positives / found share of the true positives. (B0)

Proxy task

  • L1 Auxiliary task solved only to learn good representations. (B2)

R

Residual connection

  • L1 Output = layer(x) + x; lets features pass directly and helps deep networks learn (2026 lecture). (B6)

RNN (recurrent neural network)

  • L1 Reads tokens one by one, carrying a hidden state. (B3)

ROUGE

  • L1 Suite of reference-based metrics (summarisation); higher is better. (A)

S

Self-attention

  • L1 Attention among the tokens of the same sequence. (B4)

Skip-gram

  • L1 word2vec variant: predict the surrounding words from a word. (B2)

Softmax

  • L1 Turns scores into a probability distribution: $e^{z_i}/\sum_j e^{z_j}$. (B2, B4)

Subword tokenization

  • L1 Splitting text into pieces between characters and words (e.g. bear + s). (B1)

T

Token / Tokenization

  • L1 Unit of text seen by the model / the process of cutting text into them. (B1)

Transformer

  • L1 Encoder–decoder architecture built on attention (2017, “Attention Is All You Need”). (B6)

V

Vanishing / exploding gradient

  • L1 Product of many Jacobians going to 0 / ∞ during backpropagation through time. (B3)

W

Word2vec

  • L1 2013 method learning embeddings with a proxy task (CBOW / skip-gram); “king − man + woman ≈ queen”. (B2)
